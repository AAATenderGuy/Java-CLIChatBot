# Java-CLI-ChatBot
我的第一个 Java 人工智能对话小程序！🎉

## 项目介绍
这是我独立开发的 **纯 Java 控制台聊天机器人**，是我踏入 AI 智能体开发的第一步。

本项目不依赖任何第三方框架，仅使用 **Java 基础语法 + ArrayList 集合** 实现：
- 实时控制台对话
- 自动保存完整对话历史
- 输入 exit 退出程序并打印全部聊天记录

虽然项目简单，但完整实现了 AI 对话程序最核心的「**会话记忆机制**」，是未来开发 AI Agent 的底层雏形。

## 技术栈
- Java SE
- ArrayList 动态集合（存储对话上下文）
- Java 控制台输入输出

## 功能特点
1. **实时对话交互**
   控制台循环接收用户输入，实时回复。

2. **对话历史记忆**
   使用 ArrayList 动态存储每一轮用户 / Bot 对话。

3. **安全退出机制**
   输入 `exit` 即可退出程序。

4. **对话记录汇总展示**
   退出后自动输出完整整场聊天记录。

## 运行方式
1. 使用 IDEA / Eclipse 打开项目
2. 直接运行主类
3. 在控制台输入内容开始对话
4. 输入 `exit` 结束对话并查看历史记录
